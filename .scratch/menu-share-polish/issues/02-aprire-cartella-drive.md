# 02 - Aprire la cartella Drive corrente

**What to build:** Dal menu globale l'utente puo aprire nel browser o nell'app Drive la cartella attualmente selezionata.

**Blocked by:** None - can start immediately.

**Status:** completed

- [x] Il menu contiene un'azione chiaramente denominata per aprire Drive.
- [x] L'azione usa l'ID della cartella corrente e funziona su PC e Android.
- [x] Un fallimento produce un messaggio visibile invece di non fare nulla.
